## 验收与测量口径

功能验收包括预测→预取→视图准备→实际复用，以及落空→取消→回收。C 验证任务与数据；D 验证真实视图；E 汇总。禁止用数据缓存代替视图预渲染，用预测命中代替完成准备后的实际复用。

设备实验至少包含：关闭优化、仅数据预取、数据预取加视图准备。固定设备/系统/SDK/应用源码与配置、内容版本、访问路径、网络条件和冷/热状态；预先登记实验顺序、重复次数与汇总方法，保留全部记录。实际重复次数由设备测量协议明确，不虚设为课程硬指标。

原始记录应关联 runId、interactionId、匿名 sessionId、pageId/dataKey、预测 taskId、点击/可见/可交互单调时间、实验组、预测是否命中、数据是否复用、视图是否复用、取消/失败原因，以及实际测到的内存/CPU/帧/网络记录。未测到的指标记为未测，不能填 0；会话内 B 时间不与进程级点击时间混算。

按全体访问、命中、落空、冷启动分别报告点击耗时；说明失败、缺失和被排除记录。模型只使用当时已发生的历史，真实内容参数必须在点击前可确定。没有足够数据时不外推到所有用户。内存峰值与回收后的实际占用单独测量，C 的 byteLength 不是进程内存。
