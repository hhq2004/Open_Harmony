13.1 性能分析方法论

13.1 性能分析方法论

系统级性能三板斧：HiTrace（跨进程时序）+ Perf（热点采样）+ HiSysEvent（打点指标）。方法论：先定位（哪段慢）→ 再归因（为什么慢）→ 后优化。

典型场景：启动慢归因

# 1) 拿时序 hdc shell bytrace -t 10 app sched freq idle > t.gz # Perfetto 打开 → 找长空闲/长阻塞段 # 2) 找热点（native） hdc shell hiprofiler_cmd -t perf -o /data/perf.data # 3) 打点核对 hilog | grep HiSysEvent(STARTUP_xxx) # 常见元凶：串行 IO、同步等驱动、首帧前重布局
