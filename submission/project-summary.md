# P07 项目简介（当前实现稿）

项目题目：基于用户热点触达路径预测的预加载 / 预渲染优化。

目标是在用户访问路径存在重复规律时，利用已发生的访问历史预测下一页，并在后续模块的空闲调度与资源管理支持下提前准备数据和视图，比较点击响应收益与资源成本。

当前已实现 A 的应用与采集基础：固定页面别名、默认关闭的采集开关、本次运行内的匿名会话、单调时间事件、关闭后断开路径、清除预测历史，以及 A/B/C 同步接入。B 提供有界一阶路径模型、会话隔离和离线回放；C、D、E 的主机侧模块已合入。浏览器演示可运行，并用固定静态数据展示 C 的预取和复用；OpenHarmony API 26 的 A/B/C ArkTS 工程也已编译未签名 HAP。

当前尚无目标设备/模拟器运行、C 的 OpenHarmony 数据适配、D 的真实视图复用和 E 的真实设备测量。因此没有可报告的点击加速、资源节省或真实用户命中率；最终简介应在联调和实测后按真实结果更新。

复现入口：`npm ci`、`npm run pipeline`、`npm run demo`、`npm run build:harmony`。A 的流程、接口交接与环境见 `docs/A-workflow.md`、`docs/A-integration-review.md`、`docs/environment.md`。
