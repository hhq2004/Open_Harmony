# P07 项目简介

项目题目：基于用户热点触达路径预测的预加载与预渲染优化。

项目以匿名页面访问路径预测下一页，在手动模拟的空闲窗口预取固定数据，并将准备好的文本渲染模型移交给页面。应用提供采集开关、历史清除、候选展示、任务取消与资源释放状态；测量模块以内存 JSONL 记录合成演示结果。A 至 E 的核心模块已接入 OpenHarmony API 26 的 ArkTS 演示工程，主机侧流水线与 HAP 编译通过。当前未完成真实网络预取、ArkUI 原生视图预构建和设备性能对照，因此不报告实际加速或内存收益。

源码版本：`codex/de-app-integration` 分支，基于 `b95765f` 追加应用可视化修改。DevEco 预览器已验证固定路径的一键预测命中与准备模型复用；这属于合成演示。复现命令：`npm ci`、`npm run pipeline`、`npm run build:harmony`。
